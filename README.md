I build AI tools, automate engineering workflows, and modernize legacy applications. I'm based in Victoria, BC, with more than 20 years of experience building and maintaining software.

This is my personal GitHub account. My work contributions are under [@jamesgagan](https://github.com/jamesgagan).

## Selected projects

- **[a2acast](https://github.com/husker/a2acast)** — Messaging and task delegation between coding agents on different machines, with MCP tools and integrations for Claude Code, Codex, and Copilot.
- **[RAVEN](https://github.com/bcgov/raven)** — MCP tools I built through my BC Public Service work to connect agents to engineering systems such as Jira, Confluence, source control, and CI/CD. [Read the case study](https://husker.github.io/raven.html).
- **[Autonomous application modernization](https://husker.github.io/modernization.html)** — A pipeline I built to upgrade legacy Java applications, run builds and browser checks, and use failures to guide repair. Release decisions remain with the engineering team.
- **[Bug-fixing workflow](https://husker.github.io/bug-fixing.html)** — An agent workflow that investigates application faults and prepares tickets, fixes, and pull requests for human review.
